I am a Mechatronics and Embedded Systems Engineer focused on building reliable and intelligent systems at the intersection of hardware, firmware, and software. My work spans PCB development, embedded systems, control electronics, robotics, industrial automation, and real-world product integration.

I enjoy taking ideas from concept to implementation by combining schematic design, layout, embedded development, validation, and system-level thinking. My experience includes STM32, ESP32, RP2040, Raspberry Pi, NVIDIA Jetson, ROS/ROS2, C/C++, Python, Linux, and industrial control platforms.

## Selected Projects

### 1) Access Control System
Industrial-grade fingerprint-based access control with secure identity mapping.

This project involved designing a 4-layer access control PCB in Altium, with strong emphasis on EMI/EMF reduction and multi-peripheral integration. The board includes NFC, RFID, dual fingerprint sensors, and lock control outputs to support secure access applications.

#### Key Features
- 4-layer PCB architecture
- Reduced electromagnetic interference design
- NFC and RFID support
- Dual fingerprint sensor interface
- Secure door access and lock control integration
- Industrial-grade access hardware concept

#### Technologies
- Altium
- Embedded C
- UART
- I2C
- RFID
- NFC
- PCB Design

ESP32-based UAV I/O controller using MAVLink with a Herelink ground station.

This project focused on a custom ESP32-based control and interface PCB for a UAV platform. The board manages I/O interfacing and communicates over MAVLink while supporting Herelink-based ground station control, demonstrating embedded electronics design for aerospace and autonomous systems.

#### Key Features
- ESP32-based controller design
- MAVLink communication architecture
- UAV input/output interface management
- Herelink integration
- Embedded system design for aerospace applications
